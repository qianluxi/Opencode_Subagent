# DESIGN.md — 子代理系统科普（19 页）

## 全局

**画布**：1280×720；padding 上下 60 / 左右 60；内容区 1160×600。

**配色（科技蓝，单套不混）**

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#2563EB` | 标题序号块、流程节点、主色块 |
| 辅色 | `#06B6D4` | 次级节点、图表第二序列、细节点缀 |
| 强调色 | `#F59E0B` | 关键数字、失败标记（全页 ≤ 3 处） |
| 底色 | `#FFFFFF` | 主背景 |
| 浅底 | `#F1F5F9` / `#EFF6FF` | 卡片底、结论条（每页 ≤ 2 块） |
| 正文 | `#1E293B` | 主文字 |
| 弱化 | `#64748B` | 注释、页码、次要说明 |
| 分隔线 | `#E2E8F0` | 1px 细线 |

失败/危险语义不另开色板：一律用强调橙 `#F59E0B`。

**字体**：`Microsoft YaHei`（全部中文与西文正文）+ `Consolas`（仅用于规则条文这类需要等宽观感的短句）。两种家族，不再引入第三种。

字号阶梯：封面主标 72 / 章节大字 64 / 巨型数字 96–120 / 页面主标 34 / 卡片小标 24 / 正文 18–20 / 注释 14–15。

**视觉母题**：每张内容页左上角一个 6px 主色竖条 + 上方 13px 章节小字（如 `02 一个真实案例`），标题下压一条贯通内容区的 1px 细线。全篇复用，不逐页换位。

**页尾**：仅内容页有，右下 `子代理系统科普 · NN`，14px，`#94A3B8`，y≈672。封面 / 目录 / 章节页 / 结尾页不加。

**节奏**：Hero 4 页（P1、P9、P13、P19），Supporting 10 页，Transition 4 页。相邻不同版式；等宽卡片组只用 1 次（P18）；对称版式 1 页（P2 目录）。
