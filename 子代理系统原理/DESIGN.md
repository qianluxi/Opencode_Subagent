# DESIGN.md — 子代理系统原理（18 页）

上一份《子代理系统科普》是案例版（22 篇论文那条线），这一份是原理版：
不依赖任何具体工具（OpenCode / 任何框架）、不依赖具体任务（文献 / 代码 / 调研），
只讲多代理协作的结构性原理，让读者换一个任务也能自己判断该怎么拆。

## 叙事主线

先立一个前提：多代理不是"更聪明的模型"，是"把活切成能被验收的块"（P04–P06 三条原理：交付物 / 契约 / 隔离）；
再说为什么多不等于强（P08–P10：差异、并行、制衡）；
然后回收前六条，讲它会怎么失败、以及"通过"为什么会骗人（P12–P14）；
最后给判断标准与成本结构，回答"我这活到底该不该拆"（P16–P17）。
